# تحليل بيانات الموارد البشرية باستخدام SQL Server

## نظرة عامة على المشروع

يهدف هذا المشروع إلى تحليل بيانات الموظفين باستخدام SQL Server لفهم توزيع القوى العاملة، والرواتب، والأقسام، والمسميات الوظيفية، والعلاقات الإدارية بين الموظفين والمديرين.

## الأدوات المستخدمة

- SQL Server
- SQL

## مجموعة البيانات (Dataset)

تحتوي مجموعة البيانات على 7 جداول مترابطة:

- الموظفون (Employees)
- الأقسام (Departments)
- الوظائف (Jobs)
- المواقع (Locations)
- الدول (Countries)
- المناطق (Regions)
- الأشخاص المعالون (Dependents)

## التحليلات المنفذة

يتضمن المشروع 15 تحليلًا باستخدام SQL، تغطي الموضوعات التالية:

1. عرض بيانات الموظفين حسب القسم والدولة.
2. حساب عدد الموظفين في كل قسم.
3. تحديد أعلى 5 موظفين من حيث الراتب.
4. تحليل العلاقة بين الموظفين والمديرين باستخدام Self JOIN.
5. توزيع الموظفين حسب الدولة.
6. عرض الأقسام والمدن والدول التابعة لها.
7. حساب عدد الموظفين ومتوسط الرواتب لكل قسم.
8. تحديد الأقسام التي يزيد متوسط رواتبها عن 10,000.
9. حساب إجمالي الرواتب لكل قسم.
10. تحديد أعلى راتب في كل قسم.
11. تحديد الموظفين الذين تزيد رواتبهم عن متوسط رواتب أقسامهم.
12. حساب عدد الموظفين التابعين لكل مدير.
13. فحص جودة البيانات واكتشاف القيم المفقودة.
14. حساب عدد الموظفين حسب المسمى الوظيفي.
15. حساب الإحصائيات العامة للرواتب.

## أهم النتائج (Key Findings)

- إجمالي عدد الموظفين: 40 موظفًا.
- أعلى راتب: 24,000.
- أقل راتب: 2,500.
- متوسط الرواتب: 7,977.50.
- إجمالي الرواتب: 319,100.
- أكبر عدد من الموظفين يوجد في الولايات المتحدة الأمريكية، بإجمالي 30 موظفًا.
- يحقق قسم الإدارة التنفيذية (Executive) أعلى متوسط للرواتب.

## مفاهيم SQL المستخدمة

- `INNER JOIN` — الربط الداخلي بين الجداول.
- `LEFT JOIN` — الربط الأيسر بين الجداول.
- `SELF JOIN` — ربط الجدول بنفسه.
- `GROUP BY` — تجميع البيانات.
- `HAVING` — تصفية المجموعات بناءً على شرط.
- الدوال التجميعية: `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`.
- الاستعلامات الفرعية (Subqueries).
- الجمل الشرطية `CASE WHEN`.
- ترتيب النتائج باستخدام `ORDER BY`.

## هدف المشروع

إظهار المهارات العملية في SQL، وتحليل البيانات، والاستعلام من قواعد البيانات المترابطة، وإعداد تقارير الموظفين، وتحليل الرواتب، وتقييم جودة البيانات.

## الخلاصة

يوضح هذا المشروع كيفية استخدام SQL لتحويل بيانات الموارد البشرية المترابطة إلى معلومات مفيدة تساعد على فهم هيكل القوى العاملة، وتوزيع الرواتب، والعلاقات الإدارية داخل المؤسسة.
